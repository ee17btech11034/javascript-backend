            -- We get           CORS policy    when we start this app not.
                -- CORS:  (Cross Origin)
                    -- No access to any different req if that's origin is not same as server.
                    -- If URl, port number or anything is diffrent n frontend and backend then it is CORS req for it.
                    -- prevent access to api/ req from unknown.

                    -- Solutions:
                        -- Either we can whitelist URls (which we defined in frontend)  in backend. let backend respond to these urls.
                            -- ip whitelist, domain whitlist, etc can be done
                        -- In backend, we install    `npm i cors`  then add whitelist. 
                            -- Now think of port in localhost and production as we won't know the port number in production.
                        
                        
                        -- We follow a standerd with giving proper path to api in backend   
                            -- '/api/v1/jokes'    --> this way we can whitelist all req on api.  
                        
                        -- proxy:
                            -- We put domain path in a place and then append the path in it and use that as an api. 
                            -- https://vite.dev/config/server-options#server-proxy 
                            --add Server  in vite.config.js file
                                -- means whenever there is a request on '/api' then append that proxy in start of that req.
                                -- make server feel that it is from the same host as server.
                                    -- it change the origin of req to this proxy means same as server.
                    -- now CORS errors are gone.
